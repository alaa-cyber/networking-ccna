# IPv4 Addressing (Part 2)

---

## CIDR Notation

Instead of subnet mask, we use:

/24 = 255.255.255.0  
/16 = 255.255.0.0  
/8  = 255.0.0.0  

---

## Subnet Basics

Subnetting divides a network into smaller networks.

Example:
192.168.1.0 /24

---


## Communication

- Same network → direct communication  
- Different network → go through router  

---

## Key Idea

IP addressing allows devices to communicate  
Router is required between networks
