# TCP/IP Model

## Layers

1. Application
2. Transport
3. Internet
4. Network Access

---

## Mapping with OSI

- Application → OSI (Application, Presentation, Session)
- Transport → OSI Layer 4
- Internet → OSI Layer 3
- Network Access → OSI Layer 1 & 2

---

## Key Protocols

### Application
- HTTP
- DNS
- FTP

### Transport
- TCP (reliable)
- UDP (fast)

### Internet
- IP
- ICMP

---

## Key Idea
TCP/IP is simpler than OSI and used in real networks.
