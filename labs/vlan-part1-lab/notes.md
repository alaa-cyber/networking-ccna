# VLAN Lab (Part 1)

## Objective

* Configure VLANs
* Configure switch ports
* Configure router interfaces
* Verify connectivity
* Analyze broadcast domains

---

# Topology

Three VLANs are configured on the network:

| VLAN    | Name        | Network       |
| ------- | ----------- | ------------- |
| VLAN 10 | Engineering | 10.0.0.0/26   |
| VLAN 20 | HR          | 10.0.0.64/26  |
| VLAN 30 | Sales       | 10.0.0.128/26 |

# Step 1 - Create VLANs

```bash
enable
configure terminal

vlan 10
name Engineering

vlan 20
name HR

vlan 30
name Sales
```

---

# Step 2 - Assign Access Ports

## Engineering VLAN

```bash
interface f3/1
switchport mode access
switchport access vlan 10

interface f4/1
switchport mode access
switchport access vlan 10
```

## HR VLAN

```bash
interface f5/1
switchport mode access
switchport access vlan 20

interface f6/1
switchport mode access
switchport access vlan 20
```

## Sales VLAN

```bash
interface f7/1
switchport mode access
switchport access vlan 30

interface f8/1
switchport mode access
switchport access vlan 30
```

---

# Step 3 - Configure Router Interfaces

## VLAN 10 Gateway

```bash
interface g0/0
ip address 10.0.0.62 255.255.255.192
no shutdown
```

## VLAN 20 Gateway

```bash
interface g0/1
ip address 10.0.0.126 255.255.255.192
no shutdown
```

## VLAN 30 Gateway

```bash
interface g0/2
ip address 10.0.0.190 255.255.255.192
no shutdown
```

---

# Step 4 - Verification Commands

```bash
show vlan brief
show interfaces status
show ip interface brief
show running-config
```

---

# Step 5 - Connectivity Tests

```bash
ping 10.0.0.2
ping 10.0.0.65
ping 10.0.0.129
```

Expected Result:

* Devices in the same VLAN communicate directly.
* Devices in different VLANs communicate through the router.

---

# Step 6 - Broadcast Domain Analysis

Send a broadcast packet using Packet Tracer Simulation Mode.

Observe:

* Broadcast generated by PC1 is received only by devices in VLAN 10.
* Broadcast generated by PC3 is received only by devices in VLAN 20.
* Broadcast generated by PC5 is received only by devices in VLAN 30.

---

# Key Concepts Learned

## VLAN

A VLAN is a logical separation inside a switch.

---

## Broadcast Domain

Each VLAN creates a separate broadcast domain.

Without VLANs:

1 Switch = 1 Broadcast Domain

With VLANs:

1 Switch = Multiple Broadcast Domains

---

## Access Port

An access port belongs to a single VLAN and connects end devices.

---

## Default Gateway

The router interface is used as the gateway for devices inside each VLAN.
