Cisco Networking & Cybersecurity Journey

This repository documents my learning journey in networking and cybersecurity, based on the Cisco CCNA (200-301) curriculum and complementary security training.

Objective

Build a strong foundation in networking and progressively specialize in:

Network Security
Defensive Security (Blue Team)
Security Operations (SOC)

Content Overview
1. Networking Fundamentals (CCNA)
OSI & TCP/IP models
IP addressing & subnetting
Switching (VLANs, trunking)
Routing (static & dynamic)
Network services (DHCP, NAT, DNS)
Basic network security
2. Hands-on Labs
Packet Tracer labs
Network configuration scenarios
Troubleshooting exercises

Goal

Develop practical skills to transition into a career in:

Network Security Engineer
SOC Analyst
Cybersecurity Engineer
